Vertical rhythm

Line-heights snap up to whole 0.5rem baseline rows, so the two columns stay aligned at every viewport width.

Left column

Every line box occupies a whole number of baseline rows. A heading, a caption and a paragraph can mix freely without knocking the grid out of alignment.

Small text keeps the same grid: its leading snaps up to two rows, so captions sit exactly where body text would.

Fluid font-sizes never outgrow their fixed line box, because leading is computed from each step's largest size.

Right column

Margins between blocks are whole rows too — one body line between paragraphs, two before a heading. That is the entire trick, applied without exceptions.

“The baseline grid is a promise the stylesheet keeps at every width.”

Toggle the overlay above: each rose hairline marks one 0.5rem row, painted by a single repeating gradient.

Token n is exactly n × baseline — spacing and type share one grid by construction.
